## Try during the evening

1. One of you creates an online valley and sends the invite; the other joins. Did you both connect within 10 seconds and see each other's cursor?
2. Build together for 30 minutes: paths and lanes (try a bridge over the river), every building, decor runs (fences, hedges, low walls), trees.
3. Ping each other (Alt+click), try the emotes, use "go to partner".
4. Remove something your partner made: the confirmation should ask, and they should get a note.
5. Pause from one laptop; the other should say who paused.
6. Let it run into dusk and night: lit windows, lanterns, the mood.
7. Close both tabs. Next day, reopen: is the valley exactly as you left it? Restore a backup, export a `.qoti` file and import it.
8. Start a solo valley with the network off.

## Questions

- What was the best moment? What felt like a chore?
- Was anything confusing? Where did you get stuck?
- Did each lane have enough to do? Did you need each other?
- Bugs, desyncs, performance on each laptop (fps from the debug overlay).
- Three things to change before the next iteration.
